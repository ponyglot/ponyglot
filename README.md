# ponyglot

Ponyglot core: one translation layer for your Django stack (API client, sync, django-parler and django-modeltranslation adapters).

**In development.** This release reserves the name; it contains no functionality yet.
Follow progress and join the early access at **https://ponyglot.app**.

Ponyglot is one translation layer for the Django stack: django CMS pages, Wagtail pages and
app models (django-parler, django-modeltranslation), with a shared glossary, translation
memory, delta sync and editor review. The connectors are open source (BSD-3-Clause).
